# Speech-Noise-Suppressor
위너 필터(Wiener Filter)를 활용해 노이즈 섞인 음성 신호에서 잡음을 제거(Speech Enhancement)하고 복원하는 파이썬 코드입니다.

노이즈와 signal은 867210__robinhood76__14066-school-children-ambience-loop.wav, 7021-79730-0000.wav로 형성하였으며 파일은

1. 타겟 SNR 기반 노이즈 혼합 및 데이터 저장 

2. Clean vs Noisy 음성 스펙트로그램 비교 시각화

3. 위너 필터(Wiener Filter) 기반 노이즈 억제 알고리즘 및 복원 결과
순으로 실행해주십시오.
